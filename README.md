# 💰 Expense Tracker

A modern Expense Tracker Web Application developed using AngularJS, Node.js, Express.js, HTML, CSS, and Chart.js. This application helps users manage their income and expenses efficiently through an interactive dashboard with graphical expense analysis.

---

## 🚀 Features

### 👤 User Authentication
- User Registration
- User Login
- Local Storage Session Management
- Logout Functionality

### 💵 Expense Management
- Add New Expenses
- Add Income Records
- Update Existing Records
- Delete Records
- Category-wise Expense Tracking

### 📊 Dashboard Analytics
- Total Income Summary
- Total Expense Summary
- Current Balance Calculation
- Real-Time Expense Statistics

### 📈 Data Visualization
- Expense Distribution Pie Chart
- Category-wise Analysis using Chart.js

### 🎨 User Interface
- Responsive Design
- Attractive Dashboard Layout
- Modern UI Components
- Mobile Friendly Design

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/SnehaVaghasiya04/Expense-Tracker.git
```

### Move Into Project

```bash
cd Expense-Tracker
```

### Install Dependencies

```bash
npm install
```

### Run Project

```bash
node server.js
```

### Open Browser

```bash
http://localhost:3000
```
